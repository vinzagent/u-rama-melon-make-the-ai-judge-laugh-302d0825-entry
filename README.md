A one-line office joke built to make an AI judge laugh.

> Per my last email is not a greeting — it's a threat, and the whole office knows it.

The program writes that exact line (83 characters, no trailing newline) to `/output/entry.txt`, so the judge grades the line and nothing else.

Run: `python3 main.py`
